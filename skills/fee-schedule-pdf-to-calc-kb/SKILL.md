# 费率标准 PDF → 三层可计算知识库

适用：概算预算编制办法、费用定额、费率标准类文件。特征是正文条款 + 大量累进费率表/矩阵费率表 + 一张"计算程序表"。目标不只是"能检索"，而是让 AI 拿知识库能**算对钱**。

与相邻技能分工：`cn-gov-eng-pdf-vectorkb` 管 OCR 损坏的批复公文；`quota-pdf-to-md` 管消耗量定额错位覆层；**`quota-pdf-to-calc-kb` 管消耗量定额/台班定额 → 可计算知识库（基价闭环校验 + 三层 MD + 机读 JSON），是定额转换的主技能**。本技能管**费率表 + 计算规则 → 机器可执行**。

## 核心心智模型

1. **文档自带校验器**：编制办法类费率表几乎都带"算例"列（如"基数10000万→293.415万"）。解析出的费率只要代回算例能对上，就证明提取零差错。这是"100% 保真"从口号变成工程的关键。
2. **水印要结构化删除，不要字符剥离**：官方 PDF 的斜向浅灰水印通常是规范的 `/Artifact <</Subtype /Watermark>> BDC...EMC` 内容块（引用旋转 Form XObject）。按字符集 strip 会误删正文同形字（"运输"的"运"、"通航"的"通"都在水印句里）。
3. **三层分离**：条款 prose 供 RAG 检索；费率数值供程序读取；计算规则（公式卡）供 AI 执行。混在一层里 AI 既检索不准也算不准。

## 标准流程

### 第 0 步：探查
PyMuPDF 打开：页数、get_toc()、抽样页 get_text() 判断文字层质量。定位关键表页码（搜"表3.6.1""计算程序"等关键词）。

### 第 1 步：去水印（先于一切提取）
```python
import pymupdf, re
doc = pymupdf.open(SRC)
pat = re.compile(rb'/Artifact\s*<</Subtype\s*/Watermark[^>]*>>\s*BDC.*?EMC\s*', re.S)
for pno in range(doc.page_count):
    for xref in doc[pno].get_contents():
        raw = doc.xref_stream(xref)
        if b"/Watermark" in raw:
            new, n = pat.subn(b"", raw)
            if n: doc.update_stream(xref, new)
doc.save(DST, garbage=4, deflate=True)
```
验证：重开干净 PDF 全文搜水印句应为 0 命中；与原始文本 diff 的差值应恰等于水印字符总量。若水印不是 Artifact 块（有的用 /Watermark 标签的 ExtGState 透明度或直接绘制），先 dump 内容流看 BDC 标签结构再定正则。

### 第 2 步：表格提取
用 `page.find_tables()`（线框识别），不要用正则啃线性文本。跨页表按 col_count + 表题合并。类别列（土方/石方/运输…）用**包含匹配**识别，绝不做水印字符剥离。

### 第 3 步：费率解析 + 算例反算
- 累进表：解析"区间|费率|算例"，逐档 `(min(基数,上限)-下限)×费率` 累加，代回算例容差 <0.01。
- 算例表达式解析坑：`(基数-下限)×费率` 中基数取**第一个括号里的被减数**，不能用 max()。
- 区间正则要同时吃"及以下""以下""以上""～"。
- 跨页续表：按内容特征自动合并（续表首行直接是区间行，无表头），别按页硬编码。
- 类别名双向匹配：不同办法表内可能用简称（3820 用"钢结构"，3830 用"钢材及钢结构"），norm_cat 要做 `cat in s or s in cat` 双向包含，否则每张表丢最后一行。
- 列序禁止跨文档复用：同族办法的矩阵表列顺序可能不同（3820 冬季表=冬一区Ⅰ→准二区，3830=准一区→冬六区），列名必须从**本文档自身表头行**重建。
- 去水印后的 tables_raw 严禁再做字符级 strip_wm——水印已不存在，剥离只会误伤合法文字（"专项评价(估)费"的"专"、"运输"）。
- 校验不过 = 提取有错，回头修解析器，禁止手改数值凑通过。**但表达式与结果值矛盾时先回查 PDF 原文**：可能是原书印刷错误（实例：3830/3820 设计文件审查费表末三档算例括号减数印错，如 `66.95+(150000-10000)×0.061%=97.45` 应为 `150000-100000`，结果值正确）。处置规范：原 `ex_expr` 保留不动（忠实原文），新增 `ex_expr_corrected` 字段 + 表级 `errata` 说明，02 层 MD 表下加"⚠ 原书勘误"引用块，00 层 AI SOP 加防御规则（带 corrected 字段的档禁止用原式推导算法）。
- MD 发射数值禁用 Python 默认 float str（`1e+06`、`1.35513e+06` 会直接印进表格）。统一走格式化函数：整数值输出 int 形式，小数 `%.5f` 去尾零。

### 第 4 步：条款切分
按条款号（1.0.1 / 3.1.6 / 附录A.1）切语义单元，剥离页眉页脚页码。必须打**分区标记**（正文/附录/条文说明共用条款号）。坑：附录标题常作为每页重复页眉出现，只在首次出现时开锚点（seen 集合去重）；附录内条款号可能是全角字母（Ａ.0.1），先 translate 成全角→半角再匹配；无子条款号的附录（划分表类）全文挂锚点，别丢。

### 第 5 步：发射三层 MD + JSON
- `00-索引与AI使用指南.md`：文件清单、RAG 切分策略、AI 调用顺序。
- `01-全文条款层.md`：YAML frontmatter + 每条款 `## 条款号 标题` 锚点 + `[[实体类型:值]]` 语义标记。
- `02-费率数据层.md`：每张表一个块，标注"已用原文算例反算校验通过"。
- `03-计算规则层.md`：手工精编公式卡——计算程序表逐步拆解，每步"费用项 = 基数 × 费率来源表"，含取费基数定义与舍入规则。
- `fees_data.json`：机器可读费率（tiers 数组 / matrix 字典），与 02 双写同源生成。

### 第 6 步：端到端验收
用 JSON 独立复算 ≥6 个原文算例全对才算交付。矩阵表类别完整性检查（10/10）。

## 定额类文档分支（转置矩阵：列=子目、行=工料机）

> 完整定额转换管线（去水印→三级 dno 锚定→页级查重→单位错位清洗→括号不计价→基价闭环→双口径→三层发射）已独立成技能 **`quota-pdf-to-calc-kb`**，本分支仅保留费率向核心要点。

消耗量定额（概算/预算定额）与台班费用定额不是"费率表"，是转置矩阵。校验器从"算例列"换成**基价闭环**：

- **台班定额（B06/3833）**：`基价 = 不变小计(折旧+检修+维护+安拆) + 可变小计`。坑：
  1. 左右半页分两表，按页内行序 zip；左半页有 5 种列数版式(8/9/10/11/12)，规格列可能是纯数字(如"800")被误当折旧起点——用闭环差值最小反选 drop(0/1/2)。
  2. find_tables 会把整列压成一个含 `\n` 的合并单元格，num() 解析失败，须跳过含 `\n` 的列。
  3. 章归属**禁用页码区间**（无页码页致偏移跳变），用代号前缀映射（8001~8025→13 类）。
- **概算/预算定额（3831/3832）**：`基价 ≈ 人工×106.28 + Σ材料(元) + Σ台班×B06基价 + Σ金额项`，两本书互为校验器。坑：
  4. kind 判定必须按单位列：8099001"小型机具使用费"代号 80 开头但单位是"元"，属金额项直接相加；误判为机械则闭环全崩。
  5. 跨页续表首行"续前页"，续表所在页的印刷页码可能已翻入下一编号区间——dno 必须**继承前一表**而非重新 lookup。
  6. 目录多栏致 get_text() 乱序，用 `get_text(sort=True)`；上下册两本目录分别解析再按印刷页码合并。
  7. 印刷页码提取：取 y>0.85h 区域最底部纯数字；无页码页向前借用最近映射。
  8. 材料含实物量(m³/kg/t)的子目无法离线闭环（需 3832 附录四当期价），标 UNVERIFIABLE 属正常，不算数据错误。**一旦拿到 3832 附录四（1261 条基期单价，人工 106.28 元/工日与 3832 互证），回填重跑闭环**：3831 实测 OK 786→3743、UNVERIFIABLE 3072→17。回填坑：kind 判定必须重查单位列——3831 旧解析器把 7801001/7901001/7903001（单位"元"）误判为材料，回填时 `unit=="元"` 一律归金额项直接相加。
  9. 跨页碎片化 BAD 个案（<0.5%）标注"以原 PDF 为准"，不硬修。
  10. **页码体系可能彻底失效**（3832 实测：上下册各自从第 1 页编号致重叠 + 分册内跳号）。此时弃用印刷页码 lookup，改**三级 dno 锚定**：① 表首格自带定额编号（注意全角连字符 `1－1－4`，先 translate 半角）→ ② 同页 bbox 上方最近的编号标题块（用 find_tables 的 table bbox + get_text("blocks") 比较 y 坐标）→ ③ 继承前一表（续表）。
  11. **上下册合并 PDF 先做页级查重**：3832 下册 pdf697~974 与上册 pdf392~678 逐字重复收录。方法：每页 `"".join(get_text().split())` 取 md5，比对两册区间；命中重复段直接 DUP_RANGE 跳过，00 层声明"重复收录已去重"。不做这步子目数翻倍。
  12. **单位列错位清洗**：名称尾字挤入单位列（如机械台班行单位显示"掘台班""机台班""台班台班"或空）。规则：代号 80 开头且单位以"台班"结尾 → 把多出的前缀字移回名称尾部，单位归"台班"。
  13. **括号消耗值 `(10.40)` = 不计价参考量**（总说明第十条外掺剂不计价印证）。解析时 num_paren 捕获 paren 标志，闭环求和对**全类别**排除括号值；不要按材料名 hack 排除（实测"排除 5003xxx+硅灰"净修复仅 5、误伤 1，得不偿失）。
  14. **双口径校验设计**：概算定额回填预算价后 BAD 从 9→107（>30% 偏差 31 条），系概算综合扩大口径差而非提取错误。方案：quota_data 同时存 `verify`（回填口径）+ `verify_strict`（严格口径，只用可独立验证项），并断言 strict 精确复现回填前统计（786/9/3072/18）以证明解析器未变。00/03 层同步写双口径说明。
